# 🍳 Kochwelt

Eine mehrseitige Koch-Website mit Landingpage, Rezeptseite und Kontaktformular – im Rahmen der ersten Gruppenarbeit.

## 📄 Seiten

- **Landingpage** – Einstiegsseite mit Header, Footer und ansprechendem Design nach Mockup-Vorgabe
- **Rezeptseite** – Echte Rezepte mit funktionierendem Portionenrechner
- **Kontaktseite** – Kontaktformular mit Validierung und E-Mail-Versand

## ✅ Features

- Responsives Design (Desktop & Mobile)
- Einheitlicher Header & Footer auf allen Unterseiten
- Portionenrechner (rechnet nicht ins Minus)
- Kontaktformular mit Pflichtfeldvalidierung und Erfolgs-Feedback
- Alle Links mit `cursor: pointer`

## 🛠️ Technologien

- HTML
- CSS
- JavaScript
